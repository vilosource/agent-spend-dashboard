# Research

Research briefs that informed the design of this repository.

For research on the pi extension that emits to this dashboard, see [`vilosource/pi-extensions/docs/research/`](https://github.com/vilosource/pi-extensions/tree/main/docs/research). The main brief there — [`usage-tracking-dashboard-RESEARCH.md`](https://github.com/vilosource/pi-extensions/blob/main/docs/research/usage-tracking-dashboard-RESEARCH.md) — covers the full state of the art (2026) for tracking coding-agent token usage and shipping it to a centralized dashboard. That brief was the genesis of this repo.

This directory will hold dashboard-specific research as it accrues (e.g. SPA framework choice, alerting strategy, retention policies).
